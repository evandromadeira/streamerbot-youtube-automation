# Instruções para trabalhar neste projeto

Antes de criar ou editar qualquer script C# deste repositório, leia [CODING_STANDARDS.md](CODING_STANDARDS.md) e aplique suas regras. Isso inclui scripts em src e scripts de manutenção.

CODING_STANDARDS.md é a fonte dos padrões de programação do usuário. Respeite as decisões marcadas como pendentes: não transforme propostas em migrações automáticas. Não reformate scripts não relacionados à tarefa.
